# BLW Field Guide

Use this to keep BLW notes consistent.

This is a formatting guide, not medical advice.

## Required BLW fields

### Baby portion

What part of the family meal can the baby eat?

### Set aside before

List what should happen after the baby portion is removed.

Common examples:

- salt
- spicy seasoning
- honey
- sweet glaze
- high-sodium sauce

### Texture target

Describe the physical texture.

Example: soft enough to mash between fingers.

### Cut or shape guidance

Describe how to serve each baby-appropriate component.

### Allergen notes

List relevant allergens or note that none are intentionally included.

### Choking-risk flags

Call out items that must be modified, omitted, softened, or cut differently.
