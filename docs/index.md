# Kester Family Cookbook

This site is the complete family recipe record.

It keeps the family-specific details that do not fit cleanly in a standard recipe app, especially Baby-Led Weaning adaptations.

## System boundary

| Tool | Job |
|---|---|
| Cookbook site | Complete family recipe record |
| AnyList | Shopping, meal planning, and kitchen execution copy |
| Browser recipe extension | Imports the standard recipe from this page |

## Recipe page structure

Each finalized recipe page should include:

- Standard recipe
- Ingredients
- Instructions
- JSON-LD Recipe schema
- Baby-Led Weaning adaptation
- Set-aside instructions
- Texture target
- Cut or shape guidance
- Allergen notes
- Choking-risk flags
- Family notes
- Revision history
